⚠ SISTEMA ISOLADO

Bem-vindo ao ambiente retro-futurista. Este site foi estilizado com efeitos vintage de monitor CRT, inspirado na atmosfera clássica de Alien Isolation.

◆ Características Implementadas

> SCANLINES: Ativas > CHROMATIC_ABERRATION: Ativa > FLICKER_EFFECT: Ativo > VIGNETTE: Ativa > WOBBLE_EFFECT: Ativo

◆ Personalizações Disponíveis

Você pode ajustar este efeito alterando as variáveis CSS:

/* Intensidade das linhas */ opacity: 0.15; /* 0.05 a 0.3 */ /* Cor do glowing */ color: #0f0; /* Verde, âmbar, etc */ /* Velocidade do flicker */ animation: flicker 0.15s; /* Aumentar para menos tremor */

◆ Efeito de Filme Antigo

O design combina:

  • ✓ Linhas de varredura CRT realistas
  • ✓ Tremor intermitente (flicker)
  • ✓ Distorção cromática sutil
  • ✓ Borda e vinheta escurecida
  • ✓ Movimento lateral suave
  • ✓ Fonte monoespacida (terminal)
  • ✓ Paleta de cores verde/âmbar retro

◆ Dicas de Customização

Para intensificar o efeito: Aumente a opacity dos scanlines para 0.25-0.3 ou altere a cor para #ff6600 (âmbar).

Para suavizar: Reduza a frequência do flicker alterando 0.15s para 0.3s ou remova o wobble.

Para diferentes cores: Substitua #0f0 por #ff9500 (âmbar) ou #00ffff (ciano).

◆ Compatibilidade

Totalmente compatível com navegadores modernos. Funciona em desktop, tablet e mobile com ajustes responsivos automáticos.
